ABOUT

自己紹介

あおき みく青木 未来

イラスト制作のクライアントワークを通して、相手の希望やこだわりを一つひとつ汲み取り、形にしていくことに楽しさを感じる中で、次第に「もっと幅広い形で、様々なことを届けられるものを作りたい」と考えるようになり、Webデザインに興味を持ちました。
見る人・使う人の気持ちに寄り添い、伝えたいことがきちんと伝わるWebサイト作りを目指し、新しい知識や技術に目を向け、より良いものを形にできるよう、少しずつ努力を重ねています。

経歴
■ 職業訓練校にてWeb・グラフィックデザインを学習
■ 広告代理店にてWeb制作（PHP/HTML/CSS/JavaScript）、グラフィック制作、SEOマーケティングなどを経験
  • Webサイトのフルリニューアル

    クライアント提供のデザインカンプをもとに、 コーディングを担当。Excelで制作されたグラフなどの素材も、サイトのデザインに合わせてIllustratorにて再制作しました。

  • 大手医療系企業サイト

    お知らせ更新、新規ページのデザイン・コーディング、全ページに架かるデザインの変更などを担当。

  • 企業採用サイトの運用・改善提案

    ページのリニューアル、文章校正、素材写真の補正を担当。
    Google AnalyticsやSEO調査をもとにサイト改善案を立案し、提案資料の作成からプレゼンテーションまで行いました。

  • 美容サロン

    webサイトの保守運用と、総合サロン予約サイト掲載用クーポン画像、期間限定メニューの画像・フライヤー、LINEリッチメニューのデザインなどを制作。

  • ナイトレジャー系店舗

    Webサイトの保守運用や、人物写真のフォトレタッチ（トーン補正、プライバシー保護の加工）や、キャスト紹介バナー等のプロモーション素材の制作・差し替え作業を行いました。

  • 医療系Webシステム

    phpMyAdminを使用し、Webシステムに登録された顧客情報の修正を担当。

  • ショッピングモール向けイベントの企画・提案

    インフルエンサーを起用した集客イベントについて、ターゲット・集客効果・購買促進施策を検討し、提案資料の作成を担当。

SKILL

使用スキル・ツール

Illustrator　CS6 / CC 1年 パスでのイラスト制作やアピアランスを使用した文字の装飾、CCで流行の3D機能の活用が可能です。
ショートカットキーを使用して効率的に作業が行えます。
Photoshop　CS6 / CC 1年 レイヤー効果を適切に使用し、素材の雰囲気を用途に合わせて調整することが可能です。
レイヤースタイルやフィルター機能を使用し、オリジナルの素材の制作も可能です。
GIFアニメーションバナーの制作経験もあります。
HTML / CSS 1年 デザイナーが制作したカンプの意図を読み取り、ピクセルパーフェクトに近いレベルでの記述を心がけています。
ホバーエフェクトやトランジション、キーフレームアニメーションを実装可能です。
JavaScript / jQuery 3ヶ月 AIに協力してもらい、動きを付けることが出来ます。
自分で数値を変更しタイミングの調整が可能で、コピー&ペーストするだけでなく、その都度内容を理解をするように心がけながら実装しています。
CLIP STUDIO PAINT 10年 長年の独学経験により、豊富なブラシ・素材・レイヤー機能を駆使した表現が可能です。
3D素材の適切な活用により、複雑な構図や背景、小物なども効果的に制作し、作業時間の短縮とクオリティの向上を両立できます。
AI 1年半 ChatGPT / Gemini / Claude を効果的に活用します。
情報漏洩を防ぐため、社外秘データや一次情報の入力を行わないセキュリティ対策を徹底しております。
また、業務においては著作権やコンプライアンスの観点から画像生成AIは使用せず、イラスト等の制作はすべて手作業で行っています。
AIはあくまで作業効率化のサポートとして、限定的に使用しています。
その他 Figma / Premiere / Blender / Microsoft 365 / Google Workspace
基本操作が可能です。
